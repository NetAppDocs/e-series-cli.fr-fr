= Afficher la configuration syslog - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Le `show syslog summary` la commande affiche les informations de configuration de l'alerte syslog.



== Baies prises en charge

Cette commande s'applique aux baies de stockage individuelles E4000, E2800, E5700, EF600, EF300, EF50 et EF80. Elle ne fonctionne pas sur les baies de stockage E2700 ou E5600.



== Rôles

Pour exécuter cette commande sur une baie de stockage E4000, E2800, E5700, EF600, EF300, EF50 ou EF80, vous devez avoir le rôle Storage Admin, Support Admin ou Storage Monitor.



== Syntaxe

[source, cli]
----
show syslog summary
----


== Paramètres

Aucune.



== Exemples

[listing]
----

SYSLOG SUMMARY
   Default facility: 3
   Default tag: StorageArray
   Syslog format: rfc5424
   Syslog Servers
      Server Address               Port Number
      serverName1.company.com      514
      serverName2.company.com      514

SMcli completed successfully.
----

8.40

11.70.1 a ajouté le `syslogFormat` Paramètre pour spécifier le format de message Syslog.
