= Effacer la configuration syslog - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Le `clear syslog configuration` la commande efface les informations d'alerte syslog.



[[supported-arrays]]
== Baies prises en charge

Cette commande s'applique aux baies de stockage individuelles E4000, E2800, E5700, EF600, EF300, EF50 et EF80. Elle ne fonctionne pas sur les baies de stockage E2700 ou E5600.



[[roles]]
== Rôles

Pour exécuter cette commande sur une baie de stockage E4000, E2800, E5700, EF600, EF300, EF50 ou EF80, vous devez avoir le rôle Storage Admin ou Support Admin.



[[syntax]]
== Syntaxe

[source, cli]
----
clear syslog configuration
----


[[parameters]]
== Paramètres

Aucune.



[[examples]]
== Exemples

[listing]
----

SMcli -n Array1 -c "clear syslog configuration;"

SMcli completed successfully.
----
