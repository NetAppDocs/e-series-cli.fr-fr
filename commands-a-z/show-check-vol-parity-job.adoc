= Afficher la tâche de vérification de parité du volume - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Le `show check volume parity job` affiche une tâche de parité de volume de vérification spécifiée et l'état de la tâche.



[[supported-arrays]]
== Baies prises en charge

Cette commande s'applique à n'importe quelle baie de stockage individuelle, y compris les baies EF600, EF300, EF50 et EF80, à condition que tous les packages SMcli soient installés.



[[roles]]
== Rôles

Pour exécuter cette commande sur une baie de stockage EF600, EF300, EF50 et EF80, vous devez disposer du rôle Storage Admin.



[[syntax]]
== Syntaxe

[source, cli, subs="+macros"]
----
show check volume parity job jobId=<job_id>;
----


[[parameters]]
== Paramètres

|===
| Paramètre | Description 


 a| 
`jobId`
 a| 
L'ID de la tâche de vérification de parité du volume Cette valeur est obligatoire.

|===


[[minimum-firmware-level]]
== Niveau minimal de firmware

11.80
