= Afficher les informations du protocole d'E/S de l'hôte de la baie de stockage - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
La commande  `show storageArray hostIoProtocolInformation` affiche des informations sur les paramètres du protocole d'E/S pour une baie de stockage spécifique.



[[supported-arrays]]
== Baies prises en charge

Cette commande s'applique à une baie de stockage E4000, EF50 ou EF80, à condition que tous les packages SMcli soient installés.



[[roles]]
== Rôles

Pour exécuter cette commande sur une baie de stockage E4000, EF50 ou EF80, vous devez disposer du rôle de Support Admin.



[[syntax]]
== Syntaxe

[source, cli, subs="+macros"]
----
show storageArray hostIoProtocolInfo;
----


[[parameter]]
== Paramètre

Aucune.



[[minimum-firmware-level]]
== Niveau minimal de firmware

12,00
