= Supprimer la bannière de connexion à la baie de stockage - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Le `delete storageArray loginBanner` cette commande vous permet de supprimer le fichier texte de la bannière de connexion qui a été téléchargé et enregistré précédemment.



== Baies prises en charge

Cette commande s'applique aux baies de stockage individuelles E4000, E2800, E5700, EF600, EF300, EF50 et EF80. Elle ne fonctionne pas sur les baies de stockage E2700 ou E5600.



== Rôles

Pour exécuter cette commande sur une baie de stockage E4000, E2800, E5700, EF600, EF300, EF50 ou EF80, vous devez avoir le rôle Security Admin.



== Syntaxe

[source, cli]
----
delete storageArray loginBanner
----


== Paramètres

Aucune.



== Niveau minimal de firmware

8.41
